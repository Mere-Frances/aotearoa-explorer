## Getting Started

### Prerequisites

- Node.js 20+

### Installation

    git clone https://github.com/Mere-Frances/aotearoa-explorer.git
    cd aotearoa-explorer
    npm install
    npm run dev

Open http://localhost:3000.

## Scripts
